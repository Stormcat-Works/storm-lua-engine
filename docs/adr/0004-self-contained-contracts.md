# ADR 0004: 自己完結した仕様と回帰契約

Status: accepted, 2026-09-25.

storm-lua-engineが実行・描画仕様、実装、conformanceを所有する。利用アプリはその下流に位置し、エンジンが下流実装を基準として参照する構成は採用しない。

公開リポジトリから外部アプリの元ソース、元の採取カード・観察文書・画像由来の元データ、完了済みの抽出ツールを外す。通常テストとCIはcheckoutしたエンジンだけで画面契約を評価し、下流repoをcloneしない。

採用済み731ケースの入力・期待RGBAと同梱グリフは維持する。コーパスは中立のversion付き契約へ整理し、現在の候補実装から期待値を再生成しない。ハッシュ更新には別の根拠とレビューを要求する。

元の実装を移植した事実と、新しい依存方向は別である。実際に残る移植部分・データのcopyrightとMIT許諾原文は中立の権利表示へ集約し、独立に新規作成したという誤った説明はしない。

配布ビルドはビルド時パスを正規化し、配布候補を再検査する。既存バイナリの文字列を手作業で改変しない。ローカルGit履歴の再作成・公開先へのpushは、この構成整理とは別の明示操作とする。
