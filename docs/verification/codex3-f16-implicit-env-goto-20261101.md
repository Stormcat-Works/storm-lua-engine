# Codex 第3回指摘16（goto の暗黙 _ENV 参照の見落とし）の修正 — 検証記録

対象: `crates/storm-lua-vm/src/dialect.rs`（goto の包み込み解析）
担当: w9 第60サイクル

## 指摘（Codex 第3回 #16、Medium）

```lua
goto L
local _ENV={}
::L::
return math.pi
```

素の Lua 5.3 は「local '_ENV' のスコープへ飛ぶ」として拒否するが、
書換えは `do ... end` で包んで受理し、外側の環境を読んでいた。
包み込みの可否を判定する `referenced_after` が、交差ローカルの明示的な
識別子綴りしか数えておらず、ラベル以降のグローバルアクセスが持つ
暗黙の _ENV 参照を見落としていた。

## 修正

- 交差ローカルに _ENV が含まれる場合、ラベル以降の自由名は暗黙の
  _ENV 参照として数える（フィールド名・宣言名・ラベル名・goto 先は
  従来どおり参照と数えない。フィールド名の読み飛ばしは同じ条件内に
  あるため新しい数え方にも効く）。
- 精密化: goto より前の文で宣言された同一ブロックのローカルは、
  ラベル以降でもその束縛を読むため _ENV 参照から除く。これがないと
  補助関数などの一般的な形（例: 前置きで宣言した `local function
  expect`）を過剰に拒否する。外側スコープのローカルや引数へ解決
  される名前は、走査がブロック単位であるため安全側として参照に
  数える（包まない判断は素の Lua 5.3 の挙動を保つ）。

回帰テスト2件（r3-16 形が包まれないこと、暗黙参照のない形は
引き続き包まれること）を追加。
