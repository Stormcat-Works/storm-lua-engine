## 修正

意味論不変の生成側事前判定を2つ入れた（コスト側のみ。候補集合の
同一性・スコア付け・空集合の扱いは不変）:

1. **集合メモ化**: 候補の長さは `(source, root, selected, localize,
   chunk_locals)` の決定論的な純関数であり、探索の受理判定は長さの
   比較だけで決まり、現行長は単調非増加である。したがって一度
   却下された集合は後から受理されることはなく、再比較のために
   木を再構築する必要がない。`measure_candidate` が順序つき集合を
   キーに長さを run 内でメモ化し、受理された場合に限って
   （最終の空集合チェック、初期集合とのタイ）`make_candidate` で
   再構築する——再構築結果は決定論により同一の木になる。
2. **実現不能の事前判定**: localized でチャンクのローカル予算を
   超える集合は定義により無限長なので、構築せずに無限長として
   メモ化する。空集合は常に実現可能で有限長のため、そのような
   集合が最終勝者になることはない（防御として、勝者が未構築の
   場合は使用箇所で再構築する）。

以上により Tier INVARIANT（出力不変が構造で示せる変更）として扱う。
