# 定数畳み込み接合のラベル漏れ（候補G）の修正 — 検証記録

対象: `crates/storm-lua-minify/src/passes/literal_folding.rs`
（`selected_body` と `simplify_control_flow` の Block 平坦化）
担当: w6 第61サイクル（発見は w6 第60サイクルの境界スイート v24）

## 欠陥

定数畳み込みで選択された `if`/`else` 本体を親ブロックへ接合する際の
`do` 包み条件が、本体トップレベルの `return` とローカル宣言
（`local` / `local function`）しか見ておらず、**ラベル定義を含んで
いなかった**。本体トップレベルにラベルがあると、そのラベルは接合先
ブロックの文として漏れる。

- **form 1（生成コードが不正）**: 接合先ブロックに同名ラベルが既に
  あると、同一ブロック内に同名ラベルが重複し、生成コードは
  Lua 5.3 でロード不能になる（plain は正常実行、最適化構成は全て
  vm-error）。最小再現:

  ```lua
  ::m::
  local n = 0
  if 2 > 0 then ::m:: n = 1 end
  output.setNumber(1, n)
  ```

  生成テキストは `::m::a=0::m::a=1` の形になり、ソースとして戻して
  も全構成で vm-error になる（生成コード自体が不正な直接証拠）。
  arm／else／elseif／後置ラベル／二重接合／二段選択／関数本体／
  ループ本体の各変形でも再現した（計9件）。
- **form 2（無言の意味変化）**: 接合先ブロック（または内包ブロック）
  内の `goto` が、ソースでは外側ブロックの同名ラベルへ束縛される
  ところ、接合されたラベルへ再束縛され、実行結果が変わる
  （do 宛先: n=1 → 101、ループ本体宛先: 1 → 1101、if 本体宛先:
  1 → 101。計3件）。
- 帰属: 全12件とも `constant-folding` の無効化でのみ全構成一致に
  復旧する（トグル狩りでの単独根）。

## 包み条件の監査（文種の網羅）

接合される本体のトップレベルに現れ得る文種を全て列挙し、「接合先
ブロックで意味が変わり得るか」を個別に判定した。

| 文種 | 感受性 | 判定 |
|---|---|---|
| Return | 解析上の位置制約（ブロック最終文でなければならない） | 対応済み（selected_body は常時、平坦化は非最終位置で包む） |
| Local / Localfunc | 宣言のスコープが接合先の残り全体へ広がる | 対応済み（常時包む） |
| **Label** | **ブロックのラベル名前空間を共有する: 同名ラベルの重複（解析不能）と goto の再束縛。位置によらない** | **欠落（本欠陥）** |
| Goto | 単独では非感受: ラベルとローカルが接合から排除されれば、goto の解決環境（可視ラベル集合とローカルスコープの跳躍規則）は接合前後で同一 | 包まない（対照テストで担保） |
| Break | 最内ループへの所属は祖先の性質であり Block/do の接合では不変 | 非感受 |
| Block（入れ子） | 平坦化が各段で再帰的に同じ包み条件を検査する | 各段で担保 |
| Do / While / Repeat / If / Fornum / Forin / Funcstat / Callstat / Assign | 自己完結な文、または評価順序が保存される値文。名前解決の差は本体自身のローカル宣言経由でのみ生じ、それは対応済み | 非感受 |

結論: 欠落は Label 固有であり、条件の列挙構造自体は健全だった。
接合箇所の監査: `literal_folding.rs` 内の接合は本2箇所のみ。
`fold_exact_safe_control_flow` 側は本体を常時 `do` で包み、その
Block 処理は空ブロックの除去のみで安全なことを確認した。

## 修正

- `selected_body`: 包み条件に `Node::Label(..)` を追加。
- Block 平坦化: `has_top_level_label` を追加し、ローカル宣言と
  同じく位置によらず包む（重複と再束縛は位置非依存のため）。
- 製品回帰テスト `constant_selected_body_with_label_stays_scoped`
  を追加（重複形／二つの接合が同じブロックに入る形／else 形／
  再束縛形／goto のみの本体は平坦化される対照）。修正を外すと
  失敗し、入れると成功する双方向確認済み。
