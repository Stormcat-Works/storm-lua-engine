# immutable-carrier-synthesis の試行由来なし化による追跡コスト削減（2026-10-28）

## 焦点
compile の追跡コストのうち、immutable-carrier-synthesis パス
（`immutable-carrier-synthesis`）が、出力に反映されない試行のたびに
支払っていた由来確保コスト。w1 の第29サイクルで、開発ホスト1 上で
作業した。分岐元は統合先端 `99c49982`（第108ラウンド）。

## 棚卸し・ベースライン
新先端での trackcost single（5 反復・中央値、開発ホスト1）では、
dense-normal の全コンパイル追跡差は 53,640 回で第28サイクル終了時と
一致した。immutable.lua では同パスの単独オン差が 3,071,328 回と突出
しており、次点の dense-normal での同パス差（1 回）とは対照的に、
発火系入力でのみ現れる残量であることが分かった。

## 切り分け（immutable.lua）
- directpass（5 反復・中央値）に同パスの腕を追加して測定した：
  無追跡 32,488,823 回→追跡 35,556,859 回で、追跡差は 3,068,036 回。
  synthesized=8 ラウンド、considered=10,204 候補で、候補あたり
  約 300 回の追跡側上乗せになる。saved=1491・コード長 37040・
  ノード数 10499→10539 は変更前後で同一。
- 一時変種（すべて cp 復元で除去し、git の破壊的操作は使っていない）：
  候補ループを空転させると追跡差は 1 回まで落ちた。すなわち
  ラウンド固定費（複製・resolve・解析・inspect・ベースライン測定）は
  追跡差にほぼ寄与せず、3,068,036 回のほぼ全額が候補構築時の
  由来書き込み（出現箇所ごとの rewrite＋derive＋relate と
  mark_synthetic）である。候補のサイズ測定（`measure_renamed_size`）
  は rename 計画と計測のみで由来を書かないため、測定自体は
  追跡差に寄与しない。

## 採用した変更（ローカルコミットのみ。push・PR なし）
- `crates/storm-lua-minify/src/passes/immutable_synthesis.rs` のみ
  （＋回帰テスト 1 件）。ラウンドごとに、ラウンド源の由来なしクローン
  （`clone_without_origins`。NodeId・SymbolId は保存される）を試行基盤
  とし、候補構築とサイズ測定をすべて試行基盤上で行う。勝者は
  （グループ・件数・キャリア名）だけを保持し、採用確定後に同一の
  候補構築コードを tracked なラウンド源でリプレイしてコミットする。
- 等価性の根拠：サイズ測定は由来に依存しないため勝者選択は変わらず、
  リプレイは従来の勝者候補構築と同一の源・同一の引数で行うため、
  コミットされる AST は従来と同一である。試行基盤上の由来なし実行は、
  非追跡コンパイルが従来から通っている経路そのものである。
- 回帰テスト `tracked_trial_winner_matches_untracked_output` を追加
  （勝者＋敗北グループを含む入力で、追跡経路の出力と非追跡経路の
  出力が一致すること。追跡側は監査プリンタで由来欠落 0 も検証する）。
