# 実行が保証されない Funcstat 定義の呼出しインライン化（2026-10-31、未公開）

## バグ

w6 第47サイクルの境界スイート v14 で発見（候補 A）。resolver は
Funcstat の定義文が入れ子ブロックのどこにあっても対象束縛に
`function_node` を無条件で記録し、インライン系パス群
（literal-call-folding / expression-helper-inlining /
one-use-expression-helper-reversal、および定数引数特殊化・
1 回使用関数の融合）がそれを「束縛の値」として消費していた。
定義の実行が保証されない形状では、呼出しが本体へ置換され定義文
まで除去されるため、原典の意味が失われる。

- `if input.getBool(1) then function H() return 1 end end` の後に
  `H()` を呼ぶ形: 原典は nil 呼出しエラー（vm-error）だが、
  opt / safe / target は値を返して正常終了した。`while false` 本体・
  他関数の本体内の定義でも同型（`if false` リテラルでは静的到達
  不能として事前に除去されるため不発、`while false` では発火する
  非対称も確認済み）。
- 同根の隣接形状（第48サイクルで追加確認）: 定義後に
  `H = function() return 2 end` と再代入すると呼出しが旧本体に
  化け（原典 2 に対し最適化後 1）、2 つの Funcstat 定義の間に
  挟まれた呼出しは後本体に化けた（原典 1 に対し 2）。
- 代入形 `H = function() end` を同位置に置いた形では発火せず、
  Funcstat 固有の土台であることを確認した。本体に副作用文が
  ある場合は既存の形状ゲートで不発。73 ID の単一・候補ペア
  無効化では復旧せず、ddmin で最小無効化集合が上記 3 ID の
  同時無効化であることを特定した（3 者は `function_infos` を共有）。

## 原因箇所

`crates/storm-lua-minify/src/passes/inline_functions.rs` の
`function_infos`。`function_node` と `decl_node` が記録されて
いれば、定義の支配・到達可能性・再書込みを一切確認せずに既知
関数として収集していた。resolver 側で記録を絞る案は採らなかった:
`function_node` の消費者は 20 箇所以上に及び、B3 系のように独自の
支配条件を持つものや、`function_node.is_none()` を清掃可否に使う
もの（global_stores）が混在し、記録側の変更は新たな発火を生む
危険があるためである。

## 修正

`function_infos` の収集段に `declaration_execution_guaranteed`
を追加し、次の 4 条件を全て満たす定義だけを既知関数として残す。

1. 定義が束縛の唯一の書込みであること（Funcstat は書込み 1 回、
   Localfunc は 0 回として数え、追加の書込みがあれば棄却）。
   再代入形・2 定義形をここで落とす。
2. 定義ブロックから束縛のスコープブロック（フレーム）へ、
   `do` ブロックのみを経て到達できること。if / while / repeat /
   for 本体・他関数の本体内にある定義はここで落ちる。
3. フレーム内に（関数本体を除き）goto / label / break が存在
   しないこと。
4. 定義より前に実行され得るコード（フレーム内の定義経路より前の
   文と do 経路上の前置文、およびそこから実際に呼ばれ得る関数
   本体を展開した領域）が当該束縛を読まないこと。関数本体は境界
   とし、走査済み領域に呼出しが現れた本体のみを展開するため、
   コールバック（onTick 等）が後置定義を呼ぶ正当な形状や
   do ブロック内定義の畳み込みは維持される。repeat 本体内の
   定義は実行が保証される側だが、条件 2 により保守的に落とす
   （意味は保存され、最適化機会のみを失う）。

回帰テスト 10 件を同ファイルに追加（条件分岐内定義・ループ本体
内定義・関数内定義・再代入・2 定義間呼出し・ロード時先行呼出し・
他関数経由の先行呼出しの不発と、コールバック後置定義・do
ブロック定義・分岐内 Localfunc の発火維持）。
