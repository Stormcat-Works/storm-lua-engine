# SMC の Index 書込み分割のキー単位精密化（2026-10-30）

## 変更

直線メンバ読取 CSE（SMC レイアウト、第163ラウンド）のセグメント分割を
精密化した。第163ラウンドでは Index 書込みを含む文はセグメントを
終了させていたため、他キーへの書込みでも全グループが分割されていた。
本変更では Index 書込み文はセグメント内にバリア文として残り、
グループ単位で分割する。

- バリアの種類：同一 `(base, key)` への書込みはそのグループのみを閉じる。
  動的キーによる同一基底への書込みはその基底の全グループを閉じる。
  素の Name でない対象（`a.b.y = ...` のような入れ子 Index 対象）や
  解決できない Name からの書込みは、任意の基底とエイリアスしうるため
  全グループを閉じる。呼出を含む文・メソッド対象の文は従来どおり
  セグメントを終了させる。
- バリア文の値の読取は、書込みの有効化前に評価されるため書込み前側に
  属する。書込み対象そのものは読取として数えない。
  1 文に複数対象がある場合、全対象のバリアを値の読取の後に適用する。
- 証明位置はセグメント先頭のままで、第163ラウンドと同一の保守性を保つ。
  基底がセグメント開始時にプレーンなテーブルであることと、
  サブグループのキャッシュ定義からその読取までの間にそのフィールドへ
  影響する書込みが無いことは、バリア分割により別々に保証される。
  基底自体への書込みは書込み回数（local 0 回・global ちょうど 1 回）で
  排除されており、基底のエイリアスは非エスケープ条件で排除される。

## 単体テスト

新規・更新したテストは次のとおり（計 21 件の SMC テストが成功）。

- 他キーへの書込みはグループを維持する（従来は分割していた）。
- 同一キーへの書込みは 2 読取ずつの両側を 2 個のキャッシュに分ける。
- 他グループは同一キーへの書込みを跨いで維持される。
- 動的キーによる同一基底への書込みはその基底の全グループを分ける。
- 非 Name 対象からの書込みは全グループを分ける。
- バリア文の値の読取は書込み前側に属する。
- 従来の同一キー分割テストは維持し、書込み対象を
  読取として数えないことを注記した。
