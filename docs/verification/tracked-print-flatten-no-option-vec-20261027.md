# tracked 印字の flatten における中間 Option ベクタの除去（2026-10-27、未公開）

tracked 印字の最終段階（flatten）では、arena 全体を
`Vec<Option<NodeEmission>>` へ移し替えてから、rope の葉の順に take して
排出していた。各 arena 項目はちょうど1葉から参照されるため、中間ベクタ
は排出物の順序・値には寄与せず、emission 件数分の確保と構造体移動だけ
がコストになっていた。

## 変更

- `crates/storm-lua-syntax/src/print.rs` のみ変更し、公開 API の
  シグネチャは変えていない。
- arena を `Vec<NodeEmission>` のまま取り出し、葉の順に
  `std::mem::replace` でダミー（node 0・site／token／reason なし・
  start／end 0）と置換しながら排出する。未参照の項目はベクタの破棄時に
  従来どおり破棄される。
- 葉の走査順は arena 順と一致しない（dense-normal で逆転 320 件を
  計数した）ため、順次ドレインへの置換は行わない。走査順のまま
  インデックスで取り出す設計を維持する。
- 1葉1参照の不変条件は、debug ビルド専用の `seen` ビット列で
  従来と同様に検査する（release ではコストなし）。

## 効果

- 合成入力 4 件で新旧バイナリの生成コード全文＋全排出物（node・site・
  token・start・end・理由）の SHA-256 が完全一致した（dense-normal
  10723件・dense-lexical 10726件・draw 1789件・scale-80 5363件）。
- 時間測定は計測専用マシンで旧・新バイナリの交互測定（31 反復中央値、
  順序回転・各入力 5 ラウンド、低負荷）を行った。tracked 印字の中央値
  は dense-normal で約 1.413ms から約 1.364ms（約 -3.5%、5 ラウンド中
  4 勝・1 分）、dense-lexical で約 1.397ms から約 1.345ms（約 -3.7%・
  5 勝）、draw で約 0.198ms から約 0.184ms（約 -7%・5 勝）、scale-80 で
  約 0.698ms から約 0.673ms（約 -3.6%・5 勝）だった。絶対値は計測マシン
  固有のもので、過去の他マシン系列とは比較しない。
- 実コーパス全件比較では差分 0 件だった（下記）。

## 実コーパス全件比較

- base と head のバイナリの SHA-256 が相異なることを確認した上で、
  実世界コーパス 4,155 ファイル×4条件で比較した。成功／失敗・生成
  コード・Map中核・正規化済みMap全体すべて完全一致、差分 0 件、
  欠落 0 行だった。
